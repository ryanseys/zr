# Code of conduct

zr follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in the repository, its issues, pull requests and
discussions, and wherever a person speaks for the project.

In short: be kind, assume good intent, and speak about the work, not
the person. Harassment of any kind is not accepted.

## Report a problem

Write to ryan@ryanseys.com. The maintainer reads every report, keeps
it private, and replies within a week. The Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
tell what can follow.
